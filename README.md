# Assistant DGDI Gabon

Prototype d’interface React pour l’assistant numérique de la Direction générale de la documentation et de l’immigration du Gabon.

## Fonctionnalités

- page d’accueil responsive et démarches rapides ;
- passage automatique de la question vers l’écran de conversation ;
- suggestions et historique de discussion simulé ;
- composant de suivi d’un dossier de passeport ;
- navigation adaptée aux ordinateurs, tablettes et mobiles ;
- fondations prêtes pour la connexion à une API RAG.

## Démarrage

```bash
npm install
npm start
```

## Vérification

```bash
npm run build
```

> Les réponses et données de dossier sont fictives. Le prototype ne doit pas être utilisé comme service administratif réel sans intégration, sécurité et validation DGDI.
